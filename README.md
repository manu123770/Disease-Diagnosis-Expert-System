# Disease Diagnosis Expert System

## 📌 Description
This project is a simple rule-based expert system developed using Python.  
It takes symptoms as input from the user and suggests a possible disease.

## 💡 Features
- Takes user input (yes/no)
- Uses if-else conditions
- Suggests diseases based on symptoms

## 🛠️ Technologies Used
- Python
- Visual Studio Code

## ▶️ How to Run
1. Open terminal
2. Go to project folder
3. Run the command:
   python Project1.py

## ⚠️ Challenges Faced
- Selecting correct symptoms and diseases
- Writing proper conditions in code
- Handling user input
